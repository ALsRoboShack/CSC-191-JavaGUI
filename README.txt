CSC 191 Java GUI Lab - NetBeans Starter Project
================================================

PROJECT GOAL
------------
Build a small Java Swing GUI by completing the TODO tasks in EventRegistrationFrame.java.
This project is designed for Apache NetBeans.

IMPORTANT
---------
Use Source view and write the Swing code yourself.
Do NOT create a JFrame Form and do NOT use the drag-and-drop GUI Builder.

PROJECT STRUCTURE
-----------------
CSC191_GUI_Lab_NetBeans_v4/
  src/csc191guilab/GuiLabApp.java
  src/csc191guilab/EventRegistrationFrame.java
  src/csc191guilab/RegistrationModel.java
  nbproject/
  build.xml
  GUI_Lab_Instructions_NetBeans_v4.pdf

WHAT EACH FILE DOES
-------------------
1. GuiLabApp.java
   - Main entry point.
   - Run this file to launch the starter application.

2. EventRegistrationFrame.java
   - Main lab file.
   - Complete the TODO tasks here in order.
   - Most of your coding will happen here.

3. RegistrationModel.java
   - Simple data model for storing registration values.
   - Used in Task 8 when you copy validated GUI values into an object.

4. nbproject/ and build.xml
   - NetBeans project files.
   - Leave these alone.

HOW TO OPEN THE PROJECT IN NETBEANS
-----------------------------------
1. Unzip the project folder first.
2. Open Apache NetBeans.
3. Choose File > Open Project.
4. Select the folder CSC191_GUI_Lab_NetBeans_v4.
5. In the Projects pane, expand Source Packages > csc191guilab.
6. Right-click GuiLabApp.java and choose Run File (Shift+F6).

HOW TO WORK THROUGH THE LAB
---------------------------
1. Run the starter app before editing.
2. Open EventRegistrationFrame.java.
3. Complete Task 1, then run again.
4. Continue in order through Tasks 2-8.
5. Save often and test after each visible change.

NETBEANS TIPS
-------------
- Build Project: F11
- Run Project: F6
- Run File: Shift+F6
- If NetBeans asks for a JDK, choose an installed JDK. Java 17 or later should work.
- Read compile errors in the Output window carefully; the first error is usually the most important.
